# My Routine
### A calm, local-first routine companion for Android

**Flexible reminders · simple daily actions · gentle history**

</div>

My Routine is an Android-first personal routine app concept built with **Kotlin and Jetpack Compose**. It is designed to make everyday habits easier to follow with a simple loop: choose a time window, receive a reminder, then mark it done, snooze it, or skip it.

## Designed for everyday routines

Morning and night routines, meals, water, movement breaks, exercise, and sleep can all live in one lightweight daily view. The planned app is organized around four screens:

| Today | Routines | History | Settings |
|---|---|---|---|
| See what is next | Shape your daily flow | Review recent activity | Adjust app preferences |

## Visual direction

A modern notebook feel: warm paper colors, subtle ruled lines, handwritten-style accents, simple cards, and **Material 3** interactions.

## Current project status

This repository is an early UI scaffold. The product is planned to be local-first, with no account or backend requirement. Persistence, scheduled notifications, and history are future implementation work; the repository does not yet provide a complete routine-tracking app.

## Technology

- Kotlin
- Jetpack Compose and Material 3
- Android Gradle Plugin

## Open the project

Open the repository in **Android Studio**, allow Gradle sync to finish, then run the app configuration on an emulator or Android device when the scaffold is ready. The main app entry point is `app/src/main/java/com/vignesh/myroutine/MyRoutineApp.kt`.
